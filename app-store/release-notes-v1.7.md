# Still v1.7 — App Store "What's New"

Still now stops sliding carousels. Image strips that glide sideways to
reveal the next set — like the ones on Google search results — jump
straight to their destination instead. Page-scrolling animations, such
as "back to top" buttons, now land instantly too.

Videos also stay paused more reliably. Dismissing a sign-in popup no
longer counts as permission for an unrelated video further down the
feed to start playing on its own.
